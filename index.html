ℹ️ About

🎮 Game Title

PROGAME - Programming Quiz Game

📝 Description

PROGAME is an interactive educational quiz game designed to help students test and improve their programming knowledge across multiple computer languages. Through engaging gameplay mechanics and diagnostic testing, players can identify their strengths and weaknesses in various programming topics.

Genre: Educational, Quiz, Learning Platform

🕹️ How to Play

Controls & Mechanics:

  • Click/Tap buttons to select answers
  • Choose your topic from the main menu
  • Answer questions within the time limit (15 seconds each)
  • Each correct answer adds to your score
  • Complete all questions to see your rank

🧩 Features

  • 3 Programming Languages: HTML, CSS, JavaScript, Java
  • Diagnostic Testing System for each language (20 questions each)
  • Timed quiz mode with visual countdown
  • Performance tracking and rank system
  • Interactive feedback with sound effects
  • User authentication system
  • Volume control settings

🏆 Ranking System

  • 🏆 LEGEND - 100% Perfect Score
  • 🥇 MASTER - 80% to 99%
  • 🥈 EXPERT - 60% to 79%
  • 🥉 INTERMEDIATE - 40% to 59%
  • 🎓 BEGINNER - Below 40%
